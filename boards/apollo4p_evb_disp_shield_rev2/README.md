# nsx-board-apollo4p-evb-disp-shield-rev2

Board descriptor for the Apollo4P EVB fitted with the Apollo4 Plus Display
Kit shield (AmbiqSuite board `apollo4p_evb_disp_shield_rev2`), using the
AmbiqSuite R4 provider. Same silicon/package as `apollo4p_evb`; the shield
adds populated PSRAM (APS25616N, MSPI0) and a display interface.
Hardware-validated: `nsx-psram` XIP read/write via DMA, zero mismatches.
